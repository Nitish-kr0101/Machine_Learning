TROUBLESHOOTING:
────────────────

❌ "API Connection Failed"
   → Make sure backend is running on port 8000
   → Check: python -m uvicorn backend.app.main:app --reload

❌ "Model Not Found"
   → Copy loan_model.pkl to ml_project/backend/
   → Verify file name is exact (case-sensitive)

❌ "Port Already in Use"
   → Port 8000 or 8501 in use by another process
   → Kill process or use different port: --port 8002

❌ "Database Locked"
   → Restart the application
   → Or delete database/loans.db to start fresh
