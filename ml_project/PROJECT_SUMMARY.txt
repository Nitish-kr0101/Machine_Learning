6. API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

1️⃣  SAVE APPLICATION
   Method: POST
   Path:   /api/loans/applications
   Input:  LoanApplicationCreate
   Output: LoanApplicationResponse (HTTP 201)
   
   Endpoint: http://localhost:8000/api/loans/applications
   
   Example Request:
   {
     "applicant_income": 50000,
     "coapplicant_income": 25000,
     "loan_amount": 300000,
     "loan_amount_term": 360,
     "credit_history": 1.0,
     "married": "Yes",
     "self_employed": "No",
     "education": "Graduate",
     "property_area": "Urban"
   }
   
   Example Response:
   {
     "loan_id": 1,
     "applicant_income": 50000,
     ...
     "created_at": "2024-01-28T10:30:00"
   }

2️⃣  GET APPLICATION
   Method: GET
   Path:   /api/loans/applications/{loan_id}
   Output: LoanApplicationResponse (HTTP 200)
   
   Endpoint: http://localhost:8000/api/loans/applications/1

3️⃣  MAKE PREDICTION
   Method: POST
   Path:   /api/loans/predict
   Input:  PredictionRequest
   Output: PredictionResponse (HTTP 200)
   
   Endpoint: http://localhost:8000/api/loans/predict
   
   Example Request:
   {
     "loan_id": 1
   }
   
   Example Response:
   {
     "loan_id": 1,
     "prediction": 1,
     "prediction_confidence": 0.92,
     "message": "Loan APPROVED (Confidence: 92.00%)"
   }

4️⃣  LIST APPLICATIONS
   Method: GET
   Path:   /api/loans/applications?skip=0&limit=100
   Output: List[LoanApplicationResponse] (HTTP 200)
   
   Endpoint: http://localhost:8000/api/loans/applications

5️⃣  DELETE APPLICATION
   Method: DELETE
   Path:   /api/loans/applications/{loan_id}
   Output: (HTTP 204 - No Content)
   
   Endpoint: http://localhost:8000/api/loans/applications/1

13. EXAMPLE USAGE FLOW
═════════════════════════════════════════════════════════════════════════════

SCENARIO: John applies for a ₹300,000 loan

1. FRONTEND (User Action)
   John opens http://localhost:8501
   → Fills "New Application" form
   → Income: ₹50,000
   → Loan: ₹300,000
   → Education: Graduate
   → Clicks "💾 Save Application"

2. BACKEND (Processing)
   HTTP POST to /api/loans/applications
   → Pydantic validates input
   → CRUD creates database record
   → Returns Loan ID = 42

3. FRONTEND (Confirmation)
   Displays: "✅ Application Saved! Loan ID: 42"

4. USER REQUEST (Prediction)
   Enters ID: 42
   → Clicks "🚀 Get Prediction"

5. BACKEND (ML Inference)
   HTTP POST to /api/loans/predict?loan_id=42
   → Fetch data from database
   → Load ML model
   → Prepare features
   → Run prediction
   → Store results in database
   → Return response

6. FRONTEND (Results)
   Displays: "✅ APPROVED - Confidence: 92%"

7. HISTORY (Track)
   Go to "Application History" tab
   → View all applications
   → See statistics
   → Track predictions
